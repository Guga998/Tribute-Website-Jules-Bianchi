# 🏎️ Jules Bianchi - Tribute Website

A dedicated tribute website honoring the memory and legacy of Formula 1 driver **Jules Bianchi** (1989–2015), celebrating his career, achievements, and passion for motorsport.

---

## 📖 About the Project

This static website was created using HTML5 and CSS3. It presents a biography of Jules Bianchi, highlighting key moments of his career—such as his memorable performance at the 2014 Monaco Grand Prix, where he scored the Marussia team's first-ever Championship points.
